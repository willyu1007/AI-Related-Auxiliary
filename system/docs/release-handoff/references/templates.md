# Templates

Fill these as needed; they are not existing facts. Write 「不适用」 and the reason for a field that does not apply, and 「未核实」 for a field not yet verified; never guess. Keep the headings in Chinese.

## 本机配置（不放同步文件夹）

Keep it in the local user directory, for example `~/.config/release-handoff/<目标>.md`, never in the synced folder.

```markdown

- 本机名称：
- 角色：提交方／部署方／两者

- 本机可用的运维 skill 与手册：

```
