# 日常读取契约

本技能只读取现有规则数据并消费当前有效规则，不负责创建、修改、禁用或删除规则。

## 读取原则

- `list` 只返回当前有效规则的 `id`、`summary` 和 `appliesTo`。
- `list` 不读取规则详情，也不探测外部工具。
- `get` 按需读取指定规则的完整详情。
- 不能凭摘要判断复杂语义或改写代码。

## 检查能力

当前已实现的自动处理器：

- `clang-format`：自动检查和修复；实际选项由已安装版本验证。
- `utf8-no-bom`：自动检查，无自动修复。

语义规则不需要自动处理器；命名、类型识别、注释语义等规则由审查者阅读源码和规则详情完成。未知或未实现的能力必须报告为未执行或待审查，不能报告为通过。

## 检查结果

`pass` 表示检查通过；`violation` 表示发现问题；`needs-review` 表示待语义审查；`not-executed` 表示能力或依赖未就绪；`error` 表示执行失败。
