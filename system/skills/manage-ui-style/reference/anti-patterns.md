# 反模式清单

**地板**：严格、自由、探索三种模式下一律生效。自由 ≠ AI 味。

**这份清单的作用不是"教"，是"抵消默认"。** 模型知道紫蓝渐变是陈词滥调，但没有反向配重时照样会生成——所以它必须在**生成之前**在场。事后检查太晚，而且模型会给自己找理由。

执行方式：

- `[机检]` — 一条 grep 判定，收尾时跑
- `[设计]` — 生成前载入，用来偏移默认值，**不逐条检查**
- `[抽查]` — 收尾扫一眼，只查最高频的

---

## 一、生成式 UI 的经典破绽

1. `[机检]` **未经色板授权的渐变**（`bg-gradient-*`、`from-purple-*`）。它成为标志不是因为难看，是因为它是"需要一个好看的颜色"时的默认落点。
2. `[机检]` **满屏大圆角**（`rounded-2xl` / `rounded-3xl` 泛用、裸 `rounded`）。圆角是层级信号，全都一样大等于没有信号。
3. `[机检]` **玻璃拟态**（`backdrop-blur` + 半透明白 + 细边框）。它几乎总是叠在没有内容深度的界面上。
4. `[抽查]` **标题里的装饰性 emoji**。装饰 emoji 抢走了本该由排版层级承担的工作。功能性图标另说。
5. `[设计]` **居中 hero + 三张等权特性卡**。用它之前先问：这个产品真有恰好三个同等重要的卖点吗？
6. `[抽查]` **组件库默认脸原样出街**。底盘可以用，默认 token 不换等于宣布"我们没有设计"。
7. `[设计]` **每个元素都有阴影**。阴影是"浮起来"的语义，全都浮起来就是全都没浮。
8. `[设计]` **装饰性图标堆砌**。图标帮助扫读，不填充空白。
9. `[机检]` **无意义的 hover 缩放**（`hover:scale-*`）。微交互应预示"点了会发生什么"，缩放不预示任何东西。
10. `[抽查]` **假数据长得像假数据**（`John Doe`、`Lorem ipsum`、`example@email.com`）。真实感假数据是设计的一部分——它暴露真实的截断和溢出。

## 二、结构与层级

11. `[设计]` **一屏多个"主"按钮**。主操作的定义是唯一。
12. `[设计]` **靠边框划分区域**。卡片套卡片套边框；留白和字重能做的层级不要用线做。
13. `[设计]` **层级只靠字号**。不调字重、颜色、间距，得到的是三个字号，不是层级。
14. `[设计]` **等权网格 / KPI 卡片阵**。所有内容塞进等大卡片，等于宣布所有信息一样重要，也就是都不重要。
15. `[抽查]` **空态被忽略**。空列表直接给空白表格或一行"暂无数据"。

## 三、排版

16. `[设计]` **正文行长失控**。超过 ~75 字符（中文约 40 字）不换列。
17. `[机检]` **字阶随手取值**（`text-[15px]` 这类任意值）。散落的任意值说明没有字阶体系。
18. `[设计]` **中英混排不处理**。中文正文套用拉丁行高会松散；`uppercase` 用在中文或长句上无效且损失可读性。

## 四、颜色

19. `[设计]` **颜色只用来好看**。强调色出现在与"重要 / 可操作 / 状态"无关处，它就贬值了。
20. `[设计]` **状态色不成体系**。各自随手挑绿黄红，而不是从同一套色板派生。
21. `[机检]` **对比度不达标**。正文 ≥4.5:1，大字 ≥3:1。硬性，非偏好。
22. `[设计]` **深色模式靠反色**。需要独立的层级策略：表面靠亮度递增，而不是靠阴影。
23. `[机检]` **token 之外的裸色值**。这是所有漂移里最容易累积、也最容易机检的一类。

## 五、动效

24. `[机检]` **常驻的重绘动画**（pulse / shimmer / marquee / spinner 长期在屏）。高刷屏上持续吃 GPU。
25. `[机检]` **`transition: all`**。只写命名属性。
26. `[机检]` **忽略 `prefers-reduced-motion`**。每条动效都要有降级路径。
27. `[设计]` **入场动画用在天天看的界面**。第一次有趣，第五十次是延迟。
28. `[设计]` **动效时长过长**。界面反馈超过 ~200ms 会被感知为卡顿。

## 六、交付与工程

29. `[抽查]` **只做了亮色 / 只做了桌面**。交付时才发现另一半没设计。
30. `[设计]` **不与平台惯例对齐**。手机 app 长得像网页（顶部导航、依赖 hover、点击目标过小），或桌面应用长得像手机 app（大按钮、单列、浪费横向空间）。和平台打架永远是反模式，无论那个设计单独看多好。
31. `[抽查]` **交互态缺失**。只画默认态，缺 hover / focus / active / disabled / loading / error。focus 尤其常被忽略——它是键盘可达性的全部。
32. `[设计]` **一个项目混用多套图标库**。选一套（Lucide / Heroicons / SF Symbols），线宽统一。

## 机检命令集

从 `[机检]` 条目派生。收尾时跑，命中不等于有罪——每条命中要么修，要么在交还里说明为什么合理。

```bash
rg -n 'bg-gradient|from-(purple|indigo|violet)-' src/      # 1
rg -n 'rounded-(2xl|3xl)' src/                             # 2
rg -n 'backdrop-blur' src/                                 # 3
rg -n 'hover:scale-' src/                                  # 9
rg -n '\[(#|[0-9.]+px)' src/                               # 17 23 任意值与裸色值
rg -n '#[0-9a-fA-F]{3,8}\b' src/ -g '!**/tokens.*'         # 23 token 外的裸色值
rg -n 'transition-all|transition:\s*all' src/              # 25
rg -n 'infinite' src/; rg -c 'prefers-reduced-motion' src/ # 24 26 数量要能对上
```

对比度（21）没有便宜的 grep——收尾时对**新引入的**前景/背景组合手算一次即可，不必全量扫。
