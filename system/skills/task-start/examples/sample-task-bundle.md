# Example: tracked task bundle

```text
dev-docs/active/add-export-endpoint/
├── .ai-task.yaml
├── 00-roadmap.md
├── 01-status.md
├── 02-architecture.md
├── verification.md
├── implementation.md  # optional when implementation context is non-obvious
└── pitfalls.md        # optional after a recurring hazard is evidenced
```

`01-status.md` gives a fresh session the goal and current position. `00-roadmap.md` preserves open questions, decisions, task relationships, and the phased route to completion. `02-architecture.md` and `verification.md` are standard records. Optional files exist only when their distinct context is useful.
