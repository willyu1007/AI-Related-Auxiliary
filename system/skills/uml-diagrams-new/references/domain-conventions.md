# 领域约定（中文雷达 / 仿真说明书）

在 Mermaid 语义层遵守；布局交给 draw.io / ELK。

## 流程图

- 起止：`([开始])`、`([结束])` 扁圆，不用 `(( ))` 实心圆
- 判断：`{是否…}` 菱形
- 一步一框；不把多个步骤写进同一节点
- 条件边写 `|是|`、`|否|`，语义由拓扑表达，不写 layout 字段

## 状态机

- 使用 `stateDiagram-v2`
- 「开始」用 `[*] --> 状态`；终态用 `--> [*]` 或文字「结束」状态（按项目习惯）
- **「关机」是工作状态，不是终态**

## 类图

- 类名 / 属性 / 操作分栏；属性带可见性与类型
- 关系：`<|--` 继承、`*--` 组合、`..>` 依赖（按 Mermaid classDiagram 语法）

## 结构 / 部署

- 用 `subgraph` 表示层或模块边界
- 层间关系在 Mermaid 中声明；间距偏好用 `layouts/structure-default.json`

## 语言

- 标签与用户/说明书语言一致，默认简体中文
